## 💡 프로젝트 소개
구독 서비스를 한 번 가입한 뒤 이용량이 줄어들었는데도 자동결제를 계속하거나, 다음 결제일을 놓쳐 불필요한 비용을 지출하는 경험은 흔합니다.

SubscriptionGuard는 구독 정보와 결제 일정을 한곳에서 관리하고, Android 기기에서 확인 가능한 이용 현황을 제공하여 사용자가 구독을 유지하거나 변경할지 합리적으로 판단하도록 돕는 애플리케이션입니다.
## 🎯 개발 목표
구독 통합 관리: 여러 서비스의 요금과 결제 일정을 한곳에서 확인

자동결제 실수 예방: 결제 예정일 사전 안내

이용 현황 분석: Android 앱 전면 사용 기록을 활용한 이용량 확인

구독 지출 최적화: 통신사 제휴 혜택과 결합상품 비교를 통한 비용 절감 기회 탐색

신뢰할 수 있는 추천: 데이터 수집의 한계와 할인 적용 조건을 명확히 안내
## ✨ 핵심 기능
1. 구독 등록 및 관리

서비스명, 실제 결제액, 결제 주기, 다음 결제일을 등록하고 조회·수정·삭제할 수 있습니다.

2. 앱 이용 현황 분석

Android 사용 정보 접근을 통해 앱별 전면 사용 시간을 확인합니다. TV·PC 이용량이나 백그라운드 재생 시간은 별도로 측정되지 않을 수 있습니다.

3. 결제 예정 알림

등록한 결제일을 기준으로 3일 전, 1일 전, 당일에 안내하도록 설계했습니다. 기기 설정에 따라 알림이 지연되거나 누락될 수 있습니다.

4. 맞춤형 소비 분석 및 요금 비교

별도 개발 브랜치에서는 최근 이용량 분석, 소비 유형 분류, 통신사 제휴 혜택 및 결합상품 비교 기능을 개발하고 있습니다.

추천 가격과 할인 자격은 실제 상품 조건을 확인해야 하며, 모든 구독 상품의 절대적인 최저가를 보장하지 않습니다.

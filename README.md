## 구독 서비스 관리 밎 비용 최적화 앱

### 구독 서비스를 한 눈에 관리하고 합리적인 구독 선택을 돕는다 

히어로 배너	로고 + 슬로건 + 대표 이미지	결제 보호·절약을 표현하는 배너
한 줄 메시지	해결하는 문제를 즉시 전달	"잊고 있던 구독료, 결제 전에 발견하세요"
실제 시연	앱 스크린샷 또는 짧은 GIF	구독 등록 → 분석 → 추천
핵심 기능 시각화	3~4개 기능을 아이콘·이미지로 설명	구독 관리, 결제 알림, 이용 분석, 비용 비교
Before / After	문제 상황과 개선된 경험 비교	잊은 자동결제 → 결제 전 점검
기능 명세 표	입력·처리·출력·제약을 표로 정리	심사 평가 항목에 직접 대응
